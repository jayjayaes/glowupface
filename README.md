## 사이트가 파는 하나의 생각

> 외모는 타고나는 게 아니라 관리다 다만 관리에는 순서가 있다

키도 외모의 일부다 잠 · 밥 · 자세 · 움직임이라는 같은 네 칸이
키와 외모에 동시에 걸린다 두 권은 그 뿌리에서 갈라진 두 갈래다

## 어떻게 만들어졌나

프레임워크도 빌드 과정도 없다 `index.html` 한 장과 `assets` 폴더가 전부다
그래서 어느 호스팅에 올려도 그대로 돌아가고 파일을 더블클릭해도 열린다

| 무엇 | 어디 |
|---|---|
| 사이트 전체 | `index.html` |
| 전자책 표지 | `assets/` |
| 디자인 결정 기록 | `docs/디자인-패키지.md` |
| 이어서 작업할 때 | `docs/이어서-하기.md` |

### 들어 있는 것

- **스크롤 히어로** 스크롤을 내리면 빛이 따라 내려오고 문장이 네 번 바뀐다
  영상이 준비되면 스위치 한 줄로 실제 영상 스크럽으로 바뀐다
- **금척** 왼쪽에 세로로 흐르는 금색 눈금 스크롤 따라 켜진다
- **눌러보는 순간** 누르고 있으면 눈금이 올라가고 손을 떼면 내려간다
  자기관리가 어떤 것인지 방문자가 손으로 직접 해본다
- **연락 두 갈래** 오픈채팅과 틱톡으로 바로 말 걸기 그리고 연락처 남기기 폼

### 지켜진 것

- 콘솔 오류 0개 가로 밀림 0px
- 히어로 글자 가독성 최악 픽셀 기준 9.5 ~ 14.4 대 1 (기준 3.5)
- 휴대폰 태블릿 가로로 든 폰까지 다섯 경우 전부 확인
- 모션 최소화 설정을 켜고 끄는 것을 양방향으로 존중
- 색은 전자책 표지 픽셀에서 직접 추출 금색 `#D9B45C`
- 서체는 Pretendard 한 벌 위계는 굵기와 자간으로 만든다

## 아직 안 들어간 것

- **히어로 영상** 지금은 같은 장면을 CSS와 SVG로 그려두었다
  영상 파일이 들어오면 `index.html` 의 `HAS_VIDEO` 를 `true` 로 바꾸면 살아난다
- **진짜 후기 문장** 지어내지 않았다 받으면 증거 칸에 넣는다
- **환불 규정** 문답에 한 줄 들어갈 자리가 비어 있다

## 켜는 법

파일을 더블클릭하면 그대로 열린다

인터넷에 올리려면 이 저장소의 Settings → Pages 에서
Branch 를 `main`, 폴더를 `/ (root)` 로 두면 끝이다
