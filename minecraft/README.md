# 마인크래프트 · 웹 복셀 게임

`index.html` 한 장이 전부다 프레임워크도 빌드도 CDN 의존도 없다
텍스처 이미지 파일조차 없다 픽셀은 코드가 그린다
파일을 더블클릭하면 브라우저에서 바로 돌아간다

**[열어보기](./index.html)**

## 무엇이 들어 있나

| 무엇 | 어떻게 |
|---|---|
| 지형 | 값잡음 fBm 으로 대륙과 언덕과 산등성이 · 바다와 모래 해변 |
| 동굴과 광맥 | 3차원 잡음이 돌을 파낸다 깊은 곳에 석탄과 철이 묻혀 있다 |
| 나무 | 좌표만으로 결정한다 그래서 청크 경계를 넘어도 잘리지 않는다 |
| 낮과 밤 | 8분에 하루가 간다 해가 돌고 노을이 지고 밤하늘에 별과 달이 뜬다 |
| 몹 | 돼지와 양은 낮에 풀밭을 거닌다 좀비는 밤에 서고 해가 뜨면 탄다 |
| 싸움 | 피 열 칸 · 좀비에게 맞고 높은 데서 떨어지면 아프다 · 고기를 먹으면 낫는다 |
| 캐기 | 블록마다 단단함이 다르다 꾹 누르면 게이지가 찬다 곡괭이가 있으면 빠르다 |
| 제작 | 세 칸씩 세 줄에 재료를 놓는다 제작법을 누르면 저절로 놓인다 |
| 빛 | 면마다 밝기가 다르고 구석은 어둡다 빛돌을 놓으면 둘레가 실제로 밝아진다 |

휴대폰에서는 왼쪽 동그라미로 걷고 화면을 끌어 둘러본다
점프 캐기 놓기 가방 단추가 오른쪽에 뜬다

## 제작법

| 만드는 것 | 재료 |
|---|---|
| 나무판자 ×4 | 통나무 1 |
| 막대기 ×4 | 나무판자 2 (세로) |
| 유리 ×1 | 모래 1 + 석탄 1 |
| 벽돌 ×4 | 조약돌 4 (2 × 2) |
| 빛돌 ×2 | 유리 1 + 석탄 2 |
| 철검 ×1 | 철 2 (세로) + 막대기 1 |
| 철곡괭이 ×1 | 철 3 (가로) + 막대기 2 |

철검은 때리는 힘이 세고 철곡괭이는 돌붙이를 빠르게 캔다
돌과 광석은 맨손으로도 캐지지만 아주 더디다

## 씨앗과 시각

주소 끝에 `#seed=777` 을 붙이면 그 씨앗의 세상이 열린다
`#seed=777&time=0.75` 처럼 시각도 함께 줄 수 있다 (0 해 뜰 녘 · 0.25 한낮 · 0.5 해 질 녘 · 0.75 한밤)

메뉴의 **새 월드** 는 씨앗을 새로 뽑고 **처음으로 되돌리기** 는 손댄 자리와 가방을 모두 지운다
씨앗마다 따로 `localStorage` 에 남는다 손댄 블록 · 가방 · 피 · 시각까지 그대로 이어진다

## 어떻게 돌아가나

```
잡음 → 지형 규칙 → 청크(16 x 64 x 16 Uint8Array)
      → 보이는 면만 골라 굽기(구석 그늘 + 하늘빛) → WebGL2 로 청크마다 한 번에 그리기
```

- 청크는 사람을 따라다닌다 반경 7칸 안쪽만 만들고 멀어지면 지운다
- 한 프레임이 지형 만들기와 면 굽기에 쓰는 시간은 각각 4밀리초로 묶었다
- 하늘은 화면을 덮는 삼각형 하나다 그 안에서 해와 달과 별과 노을을 계산한다
- 몹의 몸은 단위 상자 하나를 늘리고 돌려가며 예닐곱 번 그린 것이다 다리는 걸음에 맞춰 흔들린다
- 텍스처는 파일이 아니라 코드다 32 x 32 픽셀을 함수로 그려 텍스처 배열에 올린다
- 빛돌은 가장 가까운 열여섯 개만 골라 셰이더로 넘긴다 그 자리에서 거리만큼 밝아진다

### 들여다보기

콘솔에 `MC` 가 열려 있다

```js
MC.spawnMob('zombie', MC.player.x, MC.player.y, MC.player.z - 4)   // 눈앞에 좀비를 세운다
MC.give(105, 1)                                                     // 철곡괭이를 손에 쥔다
MC.sky.time = 0.75                                                  // 한밤으로 돌린다
```
