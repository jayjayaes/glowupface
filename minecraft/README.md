# 마인크래프트 · 웹 복셀 게임

`index.html` 한 장이 전부다 프레임워크도 빌드도 CDN 의존도 없다
파일을 더블클릭하면 브라우저에서 바로 돌아간다

**[열어보기](./index.html)**

## 무엇이 들어 있나

| 무엇 | 어떻게 |
|---|---|
| 지형 | 값잡음 fBm 으로 대륙과 언덕과 산등성이를 만든다 |
| 바다와 해변 | 높이 26 아래는 물이 차고 물가에는 모래가 깔린다 |
| 동굴 | 3차원 잡음이 돌을 파낸다 물 밑은 뚫지 않는다 |
| 나무 | 좌표만으로 결정한다 그래서 청크 경계를 넘어도 잘리지 않는다 |
| 블록 | 잔디 흙 돌 조약돌 모래 나무판자 통나무 나뭇잎 유리 벽돌 눈 자갈 물 기반암 |
| 부수고 놓기 | 시선이 닿는 블록에 테두리가 생기고 손댄 자리는 브라우저에 남는다 |
| 몸 | 상자 충돌 · 한 칸 턱 자동 오르기 · 헤엄 · 날기 |
| 빛 | 면마다 밝기가 다르고 구석은 어둡다 하늘이 막힌 칸은 더 어둡다 |

## 조작

| 키 | 하는 일 |
|---|---|
| `W` `A` `S` `D` | 걷기 |
| 마우스 | 둘러보기 |
| `Space` | 점프 · 두 번 누르면 날기 |
| `Shift` | 달리기 · 날 때는 내려가기 |
| 왼쪽 클릭 | 블록 부수기 |
| 오른쪽 클릭 | 블록 놓기 |
| 가운데 클릭 | 보고 있는 블록 집기 |
| `1` ~ `9` · 휠 | 손에 든 블록 고르기 |
| `F` | 날기 켜고 끄기 |
| `F3` | 좌표와 성능 보기 |
| `Esc` | 잠깐 멈추기 |

휴대폰에서는 왼쪽 동그라미로 걷고 화면을 끌어 둘러본다
점프 부수기 놓기 단추가 오른쪽에 뜬다

## 씨앗

주소 끝에 `#seed=777` 을 붙이면 그 씨앗의 세상이 열린다
메뉴의 **새 월드** 는 씨앗을 새로 뽑고 **부순 자리 되돌리기** 는 손댄 기록만 지운다
손댄 기록은 씨앗마다 따로 `localStorage` 에 쌓인다

## 어떻게 돌아가나

```
잡음 → 지형 규칙 → 청크(16 x 64 x 16 Uint8Array)
      → 보이는 면만 골라 굽기(AO 포함) → WebGL2 텍스처 배열로 한 번에 그리기
```

- 청크는 사람을 따라다닌다 반경 7칸 안쪽만 만들고 멀어지면 지운다
- 한 프레임이 지형 만들기와 면 굽기에 쓰는 시간은 각각 4밀리초로 묶었다
  세상이 넓어져도 화면이 멈추지 않는다
- 텍스처는 파일이 아니라 코드다 16 x 16 픽셀을 그때그때 그려서 텍스처 배열에 올린다
  그래서 이미지 파일이 하나도 없다
