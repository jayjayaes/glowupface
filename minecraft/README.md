# 마인크래프트 · 웹 복셀 게임

`index.html` 한 장이 전부다 프레임워크도 빌드도 CDN 의존도 없다
텍스처 이미지 파일조차 없다 픽셀은 코드가 그린다
파일을 더블클릭하면 브라우저에서 바로 돌아간다

**[열어보기](./index.html)**

## 무엇이 들어 있나

| 무엇 | 어떻게 |
|---|---|
| 지형 | 값잡음 fBm 으로 대륙과 언덕과 산등성이 · 바다와 모래 해변 |
| 동굴과 광맥 | 3차원 잡음이 돌을 파낸다 깊은 곳에 석탄과 철이 묻혀 있다 |
| 나무와 마을 | 나무는 좌표가 정한다 마을은 160칸 격자마다 있을 수도 없을 수도 있다 |
| 낮과 밤 | 8분에 하루가 간다 해가 돌고 노을이 지고 밤하늘에 별과 달이 뜬다 |
| 비와 눈 | 한동안 맑다 한동안 온다 높고 추운 데서는 눈이 온다 비는 불을 끄고 밀을 재촉한다 |
| 몹 | 돼지와 양은 낮에 거닌다 좀비는 밤에 서고 해가 뜨면 탄다 주민은 마을에 산다 |
| 거래 | 주민을 오른쪽 클릭하면 두엇씩 내놓는다 밀과 석탄과 양털을 철로 바꾼다 |
| 싸움 | 피 열 칸 · 좀비와 불과 추락에 깎이고 고기와 빵으로 찬다 |
| 캐기 | 블록마다 단단함이 다르다 꾹 누르면 게이지가 찬다 곡괭이가 있으면 빠르다 |
| 제작 | 세 칸씩 세 줄에 재료를 놓는다 제작법을 누르면 저절로 놓인다 |
| 상자와 화로 | 오른쪽 클릭으로 연다 화로는 땔감을 태워 철을 뽑고 유리를 굽는다 |
| 농사 | 괭이로 밭을 갈고 씨앗을 심는다 물가의 밭은 젖어서 빨리 자란다 |
| 물 | 샘에서 다섯 칸까지 번진다 멀어질수록 얕아지고 기댈 데가 없으면 마른다 |
| 모래와 자갈 | 받쳐 주는 것이 없으면 떨어진다 |
| 불 | 닿는 것마다 옮겨 붙는다 나무와 잎과 양털과 밀이 탄다 사람도 몹도 데인다 |
| 빛 | 구석은 어둡고 하늘이 막히면 더 어둡다 빛돌과 불은 둘레를 실제로 밝힌다 |

## 조작

| 키 | 하는 일 |
|---|---|
| `W` `A` `S` `D` | 걷기 |
| 마우스 | 둘러보기 |
| `Space` | 점프 · 두 번 누르면 날기 |
| `Shift` | 달리기 · 날 때는 내려가기 |
| 왼쪽 꾹 | 블록 캐기 · 몹 때리기 |
| 오른쪽 클릭 | 블록 놓기 · 상자와 화로 열기 · 주민과 거래 · 괭이 씨앗 부시 양동이 쓰기 |
| `E` | 가방과 제작 |
| `R` | 먹기 (고기 · 구운 고기 · 빵) |
| `1` ~ `9` · 휠 | 손에 든 것 고르기 |
| 가운데 클릭 | 보고 있는 블록 집기 |
| `T` | 시간 멈추기 |
| `F` | 날기 켜고 끄기 |
| `F3` | 좌표와 성능 보기 |
| `Esc` | 잠깐 멈추기 |

휴대폰에서는 왼쪽 동그라미로 걷고 화면을 끌어 둘러본다
점프 캐기 놓기 가방 단추가 오른쪽에 뜬다
가방 칸의 `↑` 를 누르면 그것이 손잡이 첫 칸으로 올라온다

## 제작법

| 만드는 것 | 재료 |
|---|---|
| 나무판자 ×4 | 통나무 1 |
| 막대기 ×4 | 나무판자 2 (세로) |
| 벽돌 ×4 | 조약돌 4 (2 × 2) |
| 빛돌 ×2 | 유리 1 + 석탄 2 |
| 상자 ×1 | 나무판자 8 (가운데를 비운 채) |
| 화로 ×1 | 조약돌 8 (가운데를 비운 채) |
| 철검 ×1 | 철 2 (세로) + 막대기 1 |
| 철곡괭이 ×1 | 철 3 (가로) + 막대기 2 |
| 괭이 ×1 | 철 2 (가로) + 막대기 2 |
| 부시 ×1 | 철 1 + 부싯돌 1 |
| 양동이 ×1 | 철 3 (U 모양) |
| 빵 ×1 | 밀 3 (가로) |

부싯돌은 자갈을 캐다 보면 나오고 씨앗은 잔디를 캐다 보면 나온다

### 화로에서 굽는 것

| 넣는 것 | 나오는 것 | 걸리는 시간 |
|---|---|---|
| 철광석 | 철 | 8초 |
| 모래 | 유리 | 6초 |
| 고기 | 구운 고기 | 7초 |
| 통나무 | 석탄(숯) | 9초 |
| 돌 | 조약돌 | 6초 |

땔감은 석탄 통나무 나무판자 막대기다

### 주민이 내놓는 것

밀 10 · 석탄 8 · 양털 4 · 나무판자 12 · 모래 12 · 씨앗 8 · 고기 6 을 들고 가면
철과 빵과 유리와 구운 고기와 밀로 바꿔 준다 철 셋이면 곡괭이 넷이면 검도 준다
주민마다 내놓는 것이 다르다

## 씨앗과 시각

주소 끝에 `#seed=777` 을 붙이면 그 씨앗의 세상이 열린다
`#seed=777&time=0.75` 처럼 시각도 함께 줄 수 있다
(0 해 뜰 녘 · 0.25 한낮 · 0.5 해 질 녘 · 0.75 한밤)

메뉴의 **새 월드** 는 씨앗을 새로 뽑고 **처음으로 되돌리기** 는 손댄 자리와 가방을 모두 지운다
씨앗마다 따로 `localStorage` 에 남는다 손댄 블록 · 가방 · 피 · 시각 · 상자 속 · 자라던 밀까지 이어진다
흐르는 물은 저장하지 않는다 샘만 남기면 물은 알아서 다시 흐른다

## 어떻게 돌아가나

```
잡음 → 지형 규칙 → 청크(16 x 64 x 16 Uint8Array)
      → 보이는 면만 골라 굽기(구석 그늘 + 하늘빛) → WebGL2 로 청크마다 한 번에 그리기
```

- 청크는 사람을 따라다닌다 반경 7칸 안쪽만 만들고 멀어지면 지운다
  한 프레임이 지형 만들기와 면 굽기에 쓰는 시간은 각각 4밀리초로 묶었다
- **스스로 움직이는 것들** 은 온 세상을 훑지 않는다 바뀐 자리와 그 이웃만 목록에 넣고
  10분의 1초마다 그 목록만 살핀다 한 번에 900칸까지만 본다
- 물은 층이 있다 샘은 거의 가득 차고 멀어질수록 얕아져 면을 그 높이에 맞춰 굽는다
  떨어질 때도 층을 지키기 때문에 한 샘이 골짜기를 삼키지 않는다
- 하늘은 화면을 덮는 삼각형 하나다 그 안에서 해와 달과 별과 노을을 계산한다
- 비와 눈은 사람을 따라다니는 상자 안의 알갱이다 비는 선으로 눈은 점으로 그린다
- 몹의 몸은 단위 상자 하나를 늘리고 돌려가며 예닐곱 번 그린 것이다 다리는 걸음에 맞춰 흔들린다
- 밀과 불은 상자가 아니라 엇갈린 두 장이다 앞뒤로 다 보이게 네 번 굽는다
- 텍스처는 파일이 아니라 코드다 32 x 32 픽셀을 함수로 그려 텍스처 배열에 올린다
- 빛돌과 불은 가장 가까운 열여섯 개만 골라 셰이더로 넘긴다 그 자리에서 거리만큼 밝아진다

### 들여다보기

콘솔에 `MC` 가 열려 있다

```js
MC.spawnMob('villager', MC.player.x, MC.player.y, MC.player.z - 3)  // 눈앞에 주민을 세운다
MC.give(105, 1)                                                      // 철곡괭이를 손에 쥔다
MC.sky.time = 0.75                                                   // 한밤으로 돌린다
MC.weather.on = true; MC.weather.level = 1                           // 비를 부른다
MC.villageAt(0, 0)                                                   // 이 격자에 마을이 있는지 본다
```

## 아직 안 들어간 것

- 쌓이는 눈 · 얼음 · 용암
- 농사는 밀뿐이다 · 주민은 거래만 하고 집에 들어가지 않는다
- 세상 저장은 손댄 블록만 남긴다 지형은 씨앗에서 언제나 같은 모양으로 다시 자란다
